## Description
The `Reservoir Simulation Benchmark` is a benchmark problem for evaluating reservoir operation and river basin simulation models using a multi-year simulation of the Upper Krishna River Basin in India. The dataset includes input data, benchmark solutions, and evaluation spreadsheets for multiple simulation tools.
