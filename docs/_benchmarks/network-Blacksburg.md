## Description

The Blacksburg system is based on the Blacksburg, VA distribution system, and was originally developed by Sherali et al. in 2001 as part of an optimization study.
The system has a total demand of 8,500 CMD, one reservoir, and 6.2 km of pipe. It is classified as distribution sparse-grid by Hwang & Lansey (2017) and looped by Hoagland et al. (2015).

<img src="../static/benchmarks/network-blacksburg/blacksburg_plot.png"/>

## How to Use

The Blacksburg network is provided as an .inp file and can be loaded into EPANET or any other software package
supporting .inp files.
